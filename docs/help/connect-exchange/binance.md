# How do I connect Binance to Anny?

To register with Anny, it's not necessary to have a Binance account, but in order to use Anny, yes!

So let's prepare Binance API keys and connect them to Anny.

## **Preparing Binance API keys**

In order to use Anny you need to have a BINANCE account (Spot or Futures).

You can get an additional 20% discount on Binance fees by creating an account using [this link.](https://accounts.binance.com/en/register?ref=38544507)

A very important point in this step is to create an exclusive API for Anny.

BinanceUS

Profile -> API management

Binance.com

Profile -> Account -> API management -> Criate API

Give your API a name and click on create, authenticate and confirm email.

Save the API and secret keys somewhere as you will need them to connect to Anny.

**REMEMBER** to enable the Futures account if you are going to trade on it.

**IMPORTANT: NEVER** check the "Enable withdrawals" field - this is the withdrawal permission and it's not required to operate with Anny. This will protect both, you and Anny. The withdrawal permission is not checked, just keep it as it is.

**Restricted IPs:** Put and confirm each of the following restricted IPs 18.197.221.166 3.120.52.14 3.124.90.105 3.124.91.26 3.124.99.155

In order for Anny to operate on your Futures account, you must first create a Futures account on Binance, answer the quiz, add funds and only after these steps **create an exclusive API for Anny.**

If you have already created and linked an API to Anny and then edited the API on Binance to reflect Futures, Anny won't recognize it.

It is necessary to delete/remove Anny's API, create a new one on Binance and then link to Anny.

## **Connect the API keys to Anny**

To connect the API and secret keys to Anny click on your Profile (upper right corner), then "Settings", select "Exchanges", "Add exchange" and paste the API and Secret keys.
