# How do I connect Bybit to Anny?

In order to use Anny it's necessary to have an exchange account.

So let's prepare Bybit API keys and connect them to Anny.

## **Preparing Bybit API keys**

In order to create an API it's necessary to have a Bybit account. In case you don't have one, create an account using [this link](https://www.bybit.com/en-US/register?affiliate_id=5362&group_id=0&group_type=1).

A very important point in this step is to **create an exclusive API for Anny**.

To do this, login to Bybit and access your settings: click on your profile (in the right corner) > API > Create API keys.

In the API Key usage select "Connect to Third-Party Applications" e find Anny.trade (Anny's IPs lists are already registered with Bybit).

Select the necessary key permissions. All the ones that are selected on the screen below.

By confirming the API and Private keys will be generated, save them somewhere as you will need to copy and paste them into Anny.

## Note: Your assets must be under the "Unified Trading" account.

## **Connect the API keys to Anny**

To connect the API and secret keys to Anny click on your Profile (upper right corner), then "Settings", select "Exchanges", "Add exchange" and paste the API and Secret keys.
